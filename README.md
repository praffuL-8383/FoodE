# FoodE
FoodEase is a scalable and real-time web platform built to simplify food ordering for enterprises. It centralizes the process for employees, vendors, and admins while providing live order tracking, payment integration, and role-based dashboards.

🚀 Tech Stack
Frontend: React.js, TypeScript, Tailwind CSS, ShadCN UI

Backend: Node.js, Express.js

Database: MongoDB (with Mongoose)

Real-Time Updates: WebSocket (Socket.IO)

Payments: Stripe

Email Testing: Mailtrap

📦 Features
✅ Role-Based Access (Admin, Vendor, Employee)

✅ Real-Time Order Tracking using WebSocket

✅ Secure Payments with Stripe

✅ Vendor Dashboard with live order management

✅ Admin Analytics for vendors & orders

✅ Responsive Design (Mobile & Desktop)

✅ Authentication using JWT tokens
